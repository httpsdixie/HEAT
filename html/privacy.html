Effective: · ORCHID Heat Index Monitoring System

Privacy Notice

ORCHID is a local environmental monitoring system operated by the City Government of Ormoc. This notice explains what data the system collects, how it is used, and how it is protected.

What We Collect

  • Environmental readings — temperature, humidity, atmospheric pressure, heat index, and weather condition from deployed sensor nodes.
  • Node telemetry — sensor node ID, battery level, status flags, uptime, and geographic placement coordinates.
  • Administrator account — display name, email address, and a hashed password for the single system administrator. No public user accounts exist.
  • Audit events — a log of system actions (sign-in, sign-out, sensor placement changes) for operational accountability.

What We Do Not Collect

  • No personal data from members of the public.
  • No cookies, browser fingerprints, or tracking of any kind.
  • No data is transmitted to external servers — all data is stored locally on the device running ORCHID.

How Data Is Used

Sensor data is used solely for real-time environmental monitoring, public health advisories, and historical climate analysis for Ormoc City. Audit logs are used for internal system accountability only.

Data Storage & Security

All data is stored in a local SQLite database on the host device. The administrator password is stored as a salted hash — never in plain text. Access to system controls requires authentication.
